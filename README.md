# 刷词

做六级阅读时遇到不会的词，粘进去，联网自动补上中文释义，然后按间隔反复刷到记住为止。

整个东西一个 Python 文件加一个网页，不装任何第三方依赖，数据全在你自己电脑的 `data/` 目录里。

## 它解决的是什么问题

复习六级的时候我每天做阅读，一篇下来能碰上十几个不认识的词。这些词有个特点：**它们是我自己遇到的**，跟任何一本词汇书的顺序都对不上。

我想把它们存下来反复刷，试过几类工具，都不太顺手：

**背单词 App（墨墨、不背单词这类）**：词书是别人编好的，顺序固定。有些支持收藏，但加词要一个一个搜，搜出来还得自己挑义项。我要的是「刚才文章里那个词」，不是「六级核心词表第 137 个」。

**Anki**：能存自己的词，也确实强大，但录一条卡片要填正面、填反面。做十张卡片的时间够我把这篇阅读再读一遍了。批量收词的场景它帮不上忙。

**词典 App 自带的生词本**：能存，复习功能是顺带做的，优先级和间隔都不太对路，而且导出麻烦。

所以自己写了一个。核心是三件事：

1. **词是我自己的。** 一次粘一批进去，不用一张卡一张卡地做。
2. **释义不用我查。** 加词的时候联网调有道，中文意思和音标自动补上。
3. **释义不对能改。** 有道给的是通用义项，经常不是文章里的那个意思。按 `E` 直接改，改完永久生效。

## 跑起来

需要 Python 3.8 以上，别的什么都不用装（只用标准库）。

Windows 上双击 `启动.bat`，它自己找 Python、起服务、开浏览器。黑窗口别关，关了服务就停。

其他系统或者想手动跑：

```bash
python server.py
```

端口从 8756 开始自动找空位，启动后会在窗口里打印地址，浏览器也会自动打开。想固定端口就 `python server.py --port=8760`。

第一次打开是空的。去「词表来源」页，把词粘进输入框（一行一个），点添加，等几秒释义就补上了。

## 每天怎么用

1. **刷词页**：看到一个英文单词，`1` 认识 / `2` 不认识，翻面看中文意思，`空格` 下一个。
2. **不会的和记错的进收藏**：答错自动收藏，理解错了点「其实记错了 ★」。收藏本按收藏时间排，可以只看今天收的。
3. **新词批量加**：阅读时遇到的词攒一批，粘进「词表来源」的加词框。或者装浏览器扩展，看到就右键收走。

快捷键：`1` 认识 · `2` 不认识 · `空格` 下一个 · `P` 发音 · `S` 收藏切换 · `E` 改释义 · `R` 重来本轮 · `Esc` 关弹窗。

## 功能

**自动补释义。** 加词时联网调有道，拿中文释义和音标存进 `data/dict.json`。之后断网也能刷，释义已经在了。

**释义随时能改。** 按 `E` 或者点列表里的释义直接编辑。改完写回本地释义库，不会因为重新导入词表被冲掉。

**发音。** 走有道 `dictvoice` 接口（美音），卡片上、列表每行都有喇叭，刷词页按 `P` 也能念。要联网。

**原句。** 收词的时候可以连读到的那句英文一起存。翻面之后才显示，因为原句也算提示，先看到就没得猜了。收藏本和词表里带原句的词后面有个「原句」标记，鼠标悬停看全文。用扩展划词收录时会自动带上。

**词形还原。** 阅读里遇到的多半是变形：`staples`、`running`、`carried`。直接查有道常常拿到「n. 主要产物（staple 的复数）」这种带括号的释义，不好用。现在会先判断原样结果，查不到或者释义里带「（xx 的复数／过去式／现在分词）」这类标记，就按规则猜原形再查一遍，命中就用原形的释义，提示里写上「原形 staple」。

**划词收录。** 装了扩展之后，网页上划中一个英文单词，右键「加入刷词词库」，词和所在的那句话一起发到本地服务，服务端顺手联网补释义。

**卡片默认只有单词。** 分组名、音标、搭配提示都不显示，因为它们会提前泄题（「法律/司法」这种分组名一看就知道方向）。需要的话勾上刷词页的「显示音标和搭配提示」。

**间隔复习。** 收藏词带 box 0-5，连续答对往上走，间隔 1/1/2/4/7/15 天，答错回 box 0。连对到顶自动标「已掌握」移出收藏。

**自动备份。** 每次启动服务把 `progress.json` 复制一份到 `data/backup/progress_日期_start.json`，清空记录前也会先备一份。保留最近 10 份。真出事了从里面挑一份复制回 `data/progress.json`。

## 怎么适配到你自己的电脑

这部分是开源前特意改的，原来的代码里写死了我自己机器的路径。

**Python 找不到怎么办。** `启动.bat` 会依次试：Windows 的 `py -3` 启动器 → PATH 里的 `python.exe` → `%LOCALAPPDATA%\Programs\Python\Python3x` → `C:\Python3x` → Anaconda / Miniconda / Miniforge 的常用位置。大部分人什么都不用改。

一个都不匹配的话，在项目目录里新建一个 `python_path.txt`，里面写 `python.exe` 的完整路径：

```
E:\ananconda\python.exe
```

**词表放哪都行。**

- 桌面上放一个 `生词.md`，服务启动时自动识别
- 项目目录里放 `生词*.md`（仓库自带 `生词_示例.md`，可以直接往里加）
- 页面上「词表来源」里添加任意路径

文件被挪走或者改名了不用管，服务启动时会到项目目录、桌面、文档、下载里按文件名找回来，顺便改好 `sources.json`。真找不到了，页面顶部会挂一条橙色提示条告诉你哪个文件读不到，而不是静悄悄地显示「共 0」。

就算词表暂时读不到，收藏和学过的词也不会消失，它们从 `progress.json` 兜底渲染，释义从 `dict.json` 取，标成「词表外」。

**端口被占了。** 默认从 8756 往上找到 8775。想固定：`python server.py --port=8760`。

**想躺床上用手机刷。** 默认只绑 `127.0.0.1`，只有本机能访问。同一 WiFi 下让手机打开：

```bash
python server.py --host=0.0.0.0
```

启动后会打印局域网地址，手机浏览器打开就能用（前端请求都是相对路径，换 IP 不用改配置）。这个模式没有登录鉴权，只在自己家的网络里用。

**换电脑、迁移数据。** 复制这三个文件：`data/dict.json`（释义库）、`data/progress.json`（学习记录）、你的 `生词*.md`（词表）。

## 数据存在哪，开源时什么不上传

所有东西都在项目目录里，没有账号，没有云同步，服务端只绑本机地址。

| 文件 | 内容 | 上传吗 |
| --- | --- | --- |
| `data/dict.json` | 释义库，自己的词和改过的释义 | 不上传 |
| `data/progress.json` | 学习记录，哪天刷了什么、错几次 | 不上传 |
| `data/sources.json` | 词表文件路径 | 不上传 |
| `data/backup/` | 学习记录备份 | 不上传 |
| `生词*.md` | 自己攒的词表 | 不上传 |
| `server.py`、`web/`、`extension/` | 代码 | 上传 |

`.gitignore` 已经把这些排除了，克隆下来是干净的代码加一份二十来个词的示例词表。你自己的词库从头到尾不会进 Git。

释义走的接口是有道的 `suggest` 和 `jsonapi`。这两个不是公开 API，是逆向出来的网页接口，仅供个人学习使用，别拿去商用或者高频抓取。想完全离线，断网也能刷已经存过的词，只是新词补不了释义。

## 词表格式

三种写法都认：

```
每行一个单词
| word | 中文意思 | 提示 |     ← markdown 表格行
word - 中文意思
```

`# 标题` 或者 `261008_词表1-10页` 这类非单词行会当成分组名。

导出时是四列：单词、中文意思、提示、状态。原句单独存在 `dict.json` 里，导出时跟在后面。

## 划词收录扩展

`extension/` 是个 MV3 扩展。网页上划中一个英文单词，右键「加入刷词词库」，词和读到它的那句话一起发到本地服务，服务端顺手联网补释义。

装法：Chrome 打开 `chrome://extensions`，开右上角「开发者模式」，点「加载已解压的扩展程序」，选 `extension/` 目录。Edge 一样。

点扩展图标能看到连接状态，也能改写入哪个词表、分组名叫什么。服务每次启动的端口可能变（8756 起自动找空位），扩展会在 8756–8775 里自己找一遍，找不到就提示先启动服务。

只收单个英文单词，划中一句话或者中文会提示你，不会硬塞进去。

服务端为此加了 CORS 头和 `OPTIONS` 预检处理，扩展的源是 `chrome-extension://`，跨域必须放开。服务默认只绑 `127.0.0.1`，外网连不上，放开是可以接受的。

## 间隔复习和进度

收藏词带 box 0-5，连续答对往上走，间隔 1/1/2/4/7/15 天，答错回 box 0，连对到顶自动标「已掌握」移出收藏。

没上 FSRS 这类算法，是因为这个量级用不上——FSRS 要积累上千次复习记录才跑得赢简单的 box 模型，几百个词的时候两者的实际差别很小。哪天词库真涨到几千，做成可切换的 scheduler 也不迟。

**进度不丢。** 重开页面、重启服务都还在。不保存的只有「当前刷到第几个」，重新打开会按状态重建队列：学过的词不再是新词，收藏词按到期日回来，效果是接着上次继续，不是从头开始。

每日新词上限按服务端统计的「今日已过」折算，中途关掉再打开不会又塞一整批新词进来。

进度显示的分母是本轮计划量，固定不变。答错回炉的词不计进分母，单独显示成「＋N 待巩固」，否则答错越多分母越大，看起来永远刷不完。想让队列完全不增长，取消刷词页的「不会的再排一遍」。

界面偏好（模式、打乱、上限）存在浏览器 localStorage，换浏览器会重置，不影响学习记录。

## 接口

| 接口 | 作用 |
| --- | --- |
| `GET /api/state` | 词表 + 统计 + 默认写入路径，加 `?reload=1` 强制重读 |
| `POST /api/mark` | 记录一次练习，含间隔复习推进 |
| `POST /api/fav` | 只改收藏状态，不计练习次数 |
| `POST /api/dict` | 改释义 |
| `POST /api/fill` | 联网补全缺的释义 |
| `POST /api/append` | 批量加词，写回 md。带 `ctxs:{词:原句}` 存原句，带 `fill:true` 顺手补释义 |
| `POST /api/source/add` `remove` | 增删词源 |
| `POST /api/reset` | 清空收藏或全部记录 |
| `GET /api/export?fmt=md` | 导出带释义和状态的整理表 |

## 常见问题

**双击 bat 一闪而过 / 报一堆不是内部或外部命令。** 大概率是文件被存成了 LF 换行。bat 必须 CRLF，用编辑器转成 CRLF 再跑。

**页面显示「共 0 词」。** 先看顶部有没有橙色提示条，有的话照着把词表路径找回来。没有的话去「词表来源」页手动添加词表文件。

**加词后没有中文释义。** 补释义要联网。检查网络，或者手动按 `E` 填一个。有些生僻词有道确实没有，那就自己写。

**发音没声音。** 发音走有道 `dictvoice`，要联网。系统音量也检查一下。

**能在两台电脑上用同一个词库吗。** 手动复制 `data/dict.json`、`data/progress.json` 和词表 md 就行，没有做同步。

## 踩过的坑

**`.bat` 必须 CRLF。** 用编辑器写出来容易是 LF，cmd 双击执行会逐行丢字符，报一堆「不是内部或外部命令」。另外 bat 里别写中文，`chcp 65001` 也会让 cmd 读串行。

**弹窗显隐只用 class，别用 `hidden` 属性。** CSS 里的 `.modal{display:flex}` 优先级盖过 `hidden`，弹窗会隐身盖住整页，页面看起来「点不动」。现在用 `.modal{display:none}` + `.modal.on{display:flex}`。同理别加 `[hidden]{display:none!important}` 这种全局规则，它会把 `.on` 的 flex 一起压掉。

**有道接口。** suggest 用 `q=` 不是 `word=`，释义在 `data.entries[0].explain`；jsonapi 的释义在 `ec.word[0].trs[0].tr[0].l.i[0]`，音标在 `usphone`；发音是 `dictvoice?audio=词&type=2`（type=1 英音），直接返回 mp3。

**词表只来自 md。** `dict.json` 只是释义库，不会自动把里面的词塞进词表，免得测试词混进来。唯一的例外是 `progress.json` 里有记录的词，词表读不到时它们会兜底出现。

**词表路径变了会显示成「数据全没了」。** 踩过一次：整理表被从桌面挪进了项目目录，`sources.json` 还记着桌面路径，重启后词表读成 0 个词，页面显示「共 0 新词 0 收藏」，看着像学习记录丢了，其实 `progress.json` 一直好好的。现在的处理是启动时自动找回路径 + 顶部提示条 + 记录兜底三件套。
